# PLAN TONG THE WEBSITE DEMO

## Green Bean Coffee & Tea

## 1. Muc tieu

Xay dung website demo cho **Green Bean Coffee & Tea** o muc:

* Dep ve mat giao dien.
* The hien duoc vibe thuong hieu.
* Co du noi dung de trinh bay va demo.
* Phu hop de lam bang **HTML/CSS**, JavaScript chi o muc rat nhe.

Day la **demo visual**, chua phai website van hanh that.

---

## 2. Nguyen tac scope

Toan bo plan duoc chuan hoa theo nguyen tac sau:

* Uu tien giao dien va bo cuc.
* Noi dung co the dung du lieu mau.
* Cac nut bam co the dan den section, file HTML khac, `#` hoac hien thong bao demo.
* Khong yeu cau backend, database, dang nhap, admin, dat hang, thanh toan.
* Khong yeu cau upload anh, quan ly menu, gui form that tu giao dien.
* Neu can JavaScript, chi dung cho cac tuong tac nhe nhu menu mobile, tab, filter gia lap, modal anh, alert demo.

---

## 3. Hinh thuc trien khai

Website lam bang:

* HTML
* CSS
* JavaScript co ban

Uu tien cach lam don gian:

* Moi trang la mot file HTML rieng, hoac
* Gop thanh mot landing page neu muon toi gian.

Trong bo plan nay, van giu cau truc theo tung trang de de thiet ke giao dien.

---

Thanh dieu huong dung chung:

## 7. Chuc nang cho phep trong demo

Chi giu cac chuc nang phu hop voi demo HTML:

* Chuyen trang giua cac file HTML
* Cuon toi section trong cung trang
* Menu mobile dong/mo
* Filter tab gia lap cho menu hoac mon noi bat
* Preview anh lon o muc co ban
* Alert hoac thong bao "day la demo"
* Nut `tel:` neu muon demo goi dien
* Nut mo Facebook / Google Maps neu da co link

---

## 8. Chuc nang khong lam trong demo

Khong dua vao scope:

* Dang nhap / dang ky
* Trang admin
* Quan ly don hang
* Gio hang
* Dat mon online
* Thanh toan
* Database
* API
* Gui form that
* Luu thong tin khach hang
* Upload anh tu giao dien
* Cong cu import / generate anh ben trong website

Neu can nhac den cac chuc nang nay, chi note la:

> "Khong nam trong pham vi demo visual hien tai."

---

## 9. Cach xu ly noi dung va du lieu

Vi chi lam HTML, noi dung co the duoc dat theo 1 trong 2 cach:

### Cach 1 - Uu tien

Ghi truc tiep noi dung mau trong HTML.

Phu hop khi:

* Can dung nhanh.
* So luong noi dung khong qua lon.
* Chu yeu demo giao dien.

### Cach 2 - Tuy chon

Dung mot file `config.js` nho de chua:

* Ten thuong hieu
* Danh sach mon
* Uu dai
* Anh gallery
* Thong tin lien he

Khong bat buoc phai lam neu lam tang do phuc tap.

---

## 10. Quy uoc note demo

Trong toan bo plan, cac thanh phan sau can duoc ghi chu ro:

* Form lien he: chi demo giao dien
* Filter: chi loc front-end, khong co du lieu dong
* Uu dai: noi dung minh hoa
* Menu: gia va mon co the la du lieu mau
* Bando: co the la placeholder hoac iframe tinh
* Anh: co the dung placeholder trong giai doan dau

Mau note thong nhat:

> Day la thanh phan demo visual, chua xu ly chuc nang that.

---

## 11. Ket qua ban giao mong muon

Muc tieu cuoi cung cua bo demo:

* Mo file HTML la xem duoc giao dien.
* Cac trang dong bo phong cach.
* Noi dung hop ly de thuyet trinh/demo.
* Khong co yeu cau van hanh that.

Ban giao toi thieu gom:

* Cac file HTML
* 1 file CSS dung chung
* 1 file JS neu can tuong tac nhe
* Thu muc anh / placeholder
